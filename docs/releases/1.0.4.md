# camareLOL 1.0.4 — Beta 5

**Released:** 26 November 2026
**Status:** beta / pre-release
**Tag:** `v1.0.4`
**npm:** `@wenker-ai/camarelo@beta` — the `latest` tag deliberately stays on `0.1.22`

camareLOL is a safety-first TUI installer for Arch Linux. This release adds
4K-native disk support on the write path, drops the legacy NVIDIA branch,
hardens package-name verification, and proves the installed system boots and
accepts root login in a real Arch VM.

---

## What changed in 1.0.4

### 4K-native disks

- The planner keeps geometry in `lsblk`'s 512-byte `START` units; the write
  path converts sizes and starts to the device's **logical sector size**
  (`write_sector_size`, 512/1024/2048/4096; an unusable value is refused).
- `sfdisk_script` and `sgdisk_append_args` take the sector size, align to 1 MiB
  in those units, pin `sgdisk --set-alignment`, and shrink/leave a 33-sector
  GPT tail; partitions are never grown past what the planner reserved.
- Real-tool test `core/tests/disk_write_4kn.rs` runs `sfdisk --sector-size=4096`
  on a sparse image and reads the table back; verified `vda 4096 4096` in a
  QEMU `virtio-blk-pci,logical_block_size=4096,physical_block_size=4096` guest.

### Packages

- `nvidia-580xx-dkms` removed: the proprietary legacy branch is no longer in
  the catalog. Maxwell/Pascal/Volta keep the in-tree `nouveau`; Turing and
  newer get `nvidia-open`. `nvidia` (removed in driver 590) stays absent.
- `fcitx5-bamboo` corrected to `fcitx5-bamboo-git`.
- `scripts/check_packages.py`: package-group names checked on their own
  `/groups/x86_64/<name>/` page, fall back to the search `groups` field;
  transient network failures retried (3×, backoff); unreachable APIs are
  "not verified", not "missing". Runs offline + online in CI.

### Scripted installs and acceptance

- `--root-password-file` supplies the root account password to a scripted run
  (profiles never carry passwords); `root_login_allowed` still applies.
- VM harness mounts its data disk under `/run`, never `/mnt`; `check` boots
  the installed disk, logs in as root, runs `lsblk`/`ls`/`fstab` verification.

### Verified

- `cargo test --workspace`: TUI + core + property + 4Kn integration, 0 failed.
- `./build.sh test`, `./build.sh lint`, property tests `CAMARELOL_PROP_CASES=20000`.
- `python scripts/check_packages.py` (offline + online), `check_version`,
  `check_pkgbuild`, `check_secrets`, `check_workflows`, `check_lang_table`.
- Arch VM: full install, installed disk boots, root login + verification.
